# SkillUpApp — aplicación educativa móvil

Aplicación educativa desarrollada durante servicio social para ofrecer actividades interactivas dirigidas a usuarios infantiles.

## Funcionalidades

- Perfiles de usuario y persistencia de puntuación.
- Actividades de higiene, alimentación, seguridad, reciclaje, dibujo y memoria.
- Retroalimentación inmediata, sonidos y animaciones.
- Navegación con SwiftUI y componentes reutilizables.
- Diseño centrado en instrucciones claras, progresión gradual y accesibilidad.

## Tecnologías

Swift, SwiftUI, Xcode, UserDefaults, AVFoundation y CoreHaptics.
