# Mobile CRUD

Aplicación móvil en Kotlin enfocada en el flujo CRUD: crear, consultar, actualizar y eliminar registros.

## Enfoque técnico

- Modelado de datos para una app móvil.
- Manejo de eventos y estado de interfaz.
- Práctica de arquitectura y experiencia de usuario para Android.

El proyecto se publica como muestra de código fuente; los archivos de configuración local y artefactos generados quedan fuera del repositorio.
