# Personal Web Projects

Colección de dos ejercicios de desarrollo web:

- **Web app** con HTML, CSS, JavaScript y un backend Node.js.
- **Landing page empresarial** con estructura semántica, estilos responsivos y presentación de servicios.

## Enfoque técnico

- Separación entre estructura, estilos y comportamiento.
- Diseño orientado a una experiencia clara y adaptable.
- Base para practicar integración frontend/backend y publicación web.

## Estructura

- `src/`: aplicación web principal.
- `landing-page/`: página personal/empresarial alternativa.
