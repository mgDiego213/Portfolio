# Cloud Computing Project

Trabajo de diseño y documentación de una solución en la nube, con análisis de servicios, arquitectura, seguridad y costos.

## Temas abordados

- Selección de servicios cloud.
- Diseño de arquitectura y despliegue.
- Consideraciones de seguridad, disponibilidad y operación.
- Documentación técnica para comunicar una solución.

El repositorio contiene esta síntesis profesional y no los documentos académicos originales.
