# Software Engineering Portfolio Work

Muestras de trabajo académico orientado a ingeniería de software: definición de requerimientos, organización por sprints, gestión de proyecto y documentación de entregables.

## Enfoque

- Planeación iterativa.
- Priorización y seguimiento de trabajo.
- Comunicación de decisiones técnicas y de producto.
- Uso de prácticas ágiles.

Los documentos originales se mantienen fuera del repositorio para conservar una publicación curada.
