# Diseño y diagnóstico de redes

Simulación de una red de aproximadamente 150 dispositivos y configuración de ruteo por departamentos.

## Alcance

- Direccionamiento IPv4.
- DHCP y configuración de routers y switches.
- Segmentación por departamentos.
- Análisis de tráfico y resolución ARP.
- Diagnóstico mediante ping, ipconfig y traceroute.
- Comparación de una red plana contra una red con ruteo.

## Tecnologías

Cisco Packet Tracer, IPv4, DHCP, ruteo, switches, ARP, ping y traceroute.
