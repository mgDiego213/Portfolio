# Pokémon AI Deck Builder

Concepto de producto para una herramienta de apoyo a la construcción de mazos de Pokémon TCG.

## Propuesta técnica

- Reconocimiento de cartas mediante cámara y un modelo Core ML.
- Backend FastAPI para consulta y procesamiento de información.
- Base de datos de cartas para validar y enriquecer resultados.
- Generación de mazos y análisis estratégico como apoyo a la decisión del jugador.

El entregable se conserva como portfolio conceptual de producto y arquitectura; no se publican documentos originales ni datos privados.
