# AI-Generated Visual Campaign

Proyecto de comunicación visual para manufactura inteligente, desarrollado como propuesta de campaña con herramientas de generación de imágenes.

## Enfoque

- Traducción de un tema tecnológico a una narrativa visual.
- Diseño de una propuesta coherente para un contexto industrial.
- Uso responsable de IA generativa como herramienta creativa.

Se publica únicamente la descripción del proyecto; el documento original permanece fuera del repositorio.
