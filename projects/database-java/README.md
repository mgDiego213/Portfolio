# Database + Java

Proyecto de bases de datos con consultas SQL avanzadas, reportes operativos, triggers y una capa Java para operaciones CRUD.

## Alcance

- Consultas con JOIN, UNION, GROUP BY y manipulación de fechas.
- Reportes de ventas y pacientes vigentes.
- Manejo de restricciones y excepciones.
- Triggers para control de inventario y atención al cliente.
- Conexión Java-MySQL y operaciones crear, leer, actualizar y eliminar.

## Tecnologías

Java, MySQL, SQL, JDBC, CRUD y triggers.
