# Java OOP — Academic Management Model

Proyecto de programación orientada a objetos que modela una gestión académica con entidades como alumnos, profesores, cursos, materias, salones y calificaciones.

## Conceptos demostrados

- Clases y responsabilidades de dominio.
- Encapsulamiento y relaciones entre objetos.
- Ejecución desde una clase `Main`.
- Organización de código Java en archivos independientes.

## Estructura

- `src/`: clases Java del modelo y punto de entrada.
