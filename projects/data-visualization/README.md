# Data Visualization

Notebook y visualizaciones construidas con datos abiertos para analizar desempleo, PIB, pobreza regional y estaciones climatológicas.

## Visualizaciones

- Series temporales.
- Gráficas de dispersión.
- Boxplots.
- Barras ordenadas.
- Mapas interactivos y análisis geográfico.

## Tecnologías

Python, Pandas, NumPy, Matplotlib, Seaborn, Plotly, Folium y Jupyter.
