# Evaluación de ciberseguridad para una clínica

Análisis académico de un escenario de ransomware que afecta servidores Windows, historiales médicos y dispositivos IoT.

## Alcance

- Arquitectura de la solución.
- Reporte de vulnerabilidades con CVE y CVSS.
- Análisis forense.
- Respuesta a incidentes.
- Playbook de ransomware.
- Administración de riesgos con marco ISACA.
- Políticas, controles y auditoría de cumplimiento.

## Competencias

Análisis de vulnerabilidades, Windows Server, IoT, respuesta a incidentes, forense y gestión de riesgos.
