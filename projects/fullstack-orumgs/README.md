# OrumGS — plataforma web de criptomonedas

Proyecto académico full stack para registro e inicio de sesión, gestión de usuarios por roles, consulta de precios de criptomonedas en tiempo real y visualización de gráficos.

## Implementación

- Frontend con HTML, CSS, JavaScript y Vue.js.
- Backend con Node.js y Express.
- Persistencia en MySQL.
- Autenticación con JWT y cifrado de contraseñas con bcrypt.js.
- Consumo de CoinGecko para precios y TradingView para gráficos.
- Configuración mediante variables de entorno; no se publican credenciales.
