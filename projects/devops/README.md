# DevOps y AWS

Proyecto académico orientado a automatización, infraestructura y operación de aplicaciones en la nube.

## Alcance

- Repositorio y flujo de trabajo en GitHub.
- Entorno Linux y scripts de automatización en Python.
- Plantillas CloudFormation.
- Imagen Docker para una aplicación web.
- Pipeline CI/CD.
- IAM, EC2, almacenamiento, bases de datos, monitoreo y registro de eventos.
- Arquitectura de microservicios.

## Tecnologías

AWS, Linux, Python, Docker, CloudFormation, CI/CD, IAM, EC2, S3 y monitoreo.
