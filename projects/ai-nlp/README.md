# AI / NLP

Mini proyecto de procesamiento de lenguaje natural sobre reseñas de IMDB y clasificación de texto.

## Contenido

- Tokenización con NLTK.
- Lematización.
- Etiquetado POS.
- Reconocimiento de entidades nombradas.
- Exploración de una red neuronal sin NLTK usando PyTorch.

## Tecnologías

Python, NLTK, PyTorch y procesamiento de texto.
