# Diego Moya Silva — Software Development Portfolio

Portfolio técnico de Diego Moya Silva, estudiante de Ingeniería en Desarrollo de Software.

Este repositorio reúne proyectos seleccionados de desarrollo web y móvil, bases de datos, datos e inteligencia artificial, cloud/DevOps, ciberseguridad y redes. Se incluyen descripciones técnicas, decisiones de diseño y enlaces a proyectos relacionados.

## Áreas técnicas

- Desarrollo full stack: JavaScript, Vue.js, Node.js, Express, HTML, CSS, MySQL y APIs REST.
- Desarrollo móvil: Swift, SwiftUI, Xcode y Kotlin.
- Datos e IA: Python, Pandas, NumPy, Matplotlib, Seaborn, Plotly, Folium, NLP y visión por computadora.
- Cloud y DevOps: AWS, Linux, Docker, CloudFormation, CI/CD, IAM, EC2, S3, monitoreo y microservicios.
- Seguridad y redes: CVE/CVSS, respuesta a incidentes, análisis forense, Packet Tracer, IPv4, DHCP, ruteo y segmentación.
